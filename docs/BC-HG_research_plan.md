# 研究計画書

## テーマ

**強化学習を用いて同時間スケールで追従学習するフォロワーの下での BC-HG の評価および改良**

仮題：Tracking-Aware Hypergradient Methods for Decentralized Bilevel Reinforcement Learning

## 背景と目的

BC-HG は最大エントロピー目的を持つフォロワーの最適反応を利用し、リーダーのバイレベル目的のハイパー勾配を推定する。既存の Four-Rooms・MG toy 実験では、有限回 soft Q-iteration と Reset-Q／Carry-Q を比較し、Carry-Q では少数回の更新でも最適性ギャップが減少し、リーダーが学習できることを確認している。しかし、この全状態・行動更新は、探索不足、サンプリング雑音、関数近似、actor–critic の不整合を含まない。

本研究では、フォロワーをサンプルベースの RL に置き換え、最適反応への収束を待たずにリーダーを更新する。BC-HG が機能する条件と性能低下の原因を明らかにし、追従状態に応じたリーダー更新制御を検討する。性能低下や改良の成功は研究仮説であり、事前に結論としない。

情報アクセス条件は共有論文に従う。フォロワーの現在の方策・価値関数へのアクセスを許す一方、その学習過程を微分したり、リーダーが更新則を改変したりすることは要求しない。「最適化過程に依存しない」ことと「方策・価値も観測できない完全ブラックボックス」を区別し、後者は主題に含めない。

## 実験概要

1. **離散診断**：既存の有限回 Carry-Q を参照し、Four-Rooms／MG toy で tabular soft Q-learning、次に SAC-Discrete を用いる。必要なら tabular actor–critic を中間比較に加える。最適反応・価値・ハイパー勾配の数値参照を用いて誤差を切り分ける。
2. **既存連続タスク**：Building Thermal Control と bilevel-LQR MG のフォロワーを RL 化する。Riccati 解を厳密な参照として扱える線形・非飽和条件と、クリッピング等を含む実装条件を分ける。
3. **非線形タスク**：CartPole／Pendulum をバイレベル化する。標準 CartPole の離散行動と、共有コードにある連続行動 GuidedCartPole を区別する。
4. **高次元制御**：簡単な環境で設定を確定してから、Reacher または HalfCheetah の報酬設計型タスクに展開する。

主な比較は Online BC-HG、直接項のみの Naive-PGD、更新制御を加えた BC-HG、多更新 follower、利用可能な環境での最適反応参照条件とする。follower 更新数を主軸、leader 学習率を感度分析軸とし、小規模環境だけで交互作用を調べる。環境ステップ、更新数、計算時間を別々に計上する。

## 理論概要

目標勾配を $h^*(\theta)=\nabla_\theta J_L(\theta,g^*(\theta))$ とし、オンライン推定との偏差を、follower 追従、価値推定、actor と Boltzmann 方策の不整合、軌跡・分布の非定常性、推定雑音に分ける。

まず有限状態・行動で正則性を明示した誤差評価を目指し、soft Bellman 作用素の縮小性を利用して既存 Carry-Q の追従挙動を説明する。次に、訪問頻度・混合性・学習率等の条件付きで tabular sample-based 更新へ進む。同時間スケールという更新頻度だけから収束を主張せず、結合系の安定性条件と残留誤差を扱う。deep SAC 全体の大域収束保証は目標にしない。

改良候補は、検証用データで測った Bellman／actor residual に応じたリーダー学習率・更新幅の制御である。固定の小さい学習率とも比較し、単なる学習の減速以上の効果があるか検証する。理論は未証明の目標と成立済みの事実を区別する。

## 実施方針と追加テーマ

利用資源は CPU 40物理コア／80スレッド、GPU A5000×3、RAM 192 GB。小規模な予備実験で実行時間とメモリを測定し、独立 seed を中心に並列化する。主実験を優先し、すべてのタスクに全条件を掛け合わせない。

余力があれば、エントロピー正則化リーダー目的への BC-HG 拡張を追加する。フォロワー温度は主実験では固定し、リーダーエントロピーの効果は独立した ablation として検証する。

成果物は、再現可能なオンライン follower 評価プロトコル、誤差と学習挙動の対応、条件付き理論評価、および有効性を確認できた場合の tracking-aware 改良法とする。
